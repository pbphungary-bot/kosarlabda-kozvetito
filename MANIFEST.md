## 1. Purpose
Basketball commentator tool for the Hungarian NB I/A (men + women, always separate):
1. **Közvetítőhub** (`index.html`, `css/dashboard.css`) – match preparation dashboard (schedule/results, standings, team pages, head-to-head, notes, news, match sheet).
2. **Graphics Studio** (`graphics/`) – browser-based broadcast graphics from the owner's PSD designs, exported as transparent 1920×1080 PNG (and a ZIP package per match).

## 5b. Live statistics graphics (player insert, team comparison, three leaders; owner request 2026-11-23, all three merged 2026-11-25)
Goal: during timeouts / quarter breaks show live statistics of the running game from the MKOSZ netcasting feed, as transparent PNG: one player (`livestat`), both teams (`liveteam`), the three best-VAL players of each team (`liveleaders`). **OBS / who serves what (DECIDED 2026-11-25, BUILT and running):** ONE central computer (Windows, owner's) runs `python tools/live_server.py` (relay + builder + overlay pages + a Cloudflare tunnel); commentators use their own game links from anywhere at `https://live.livegolf.eu`; nothing is hard-wired to one machine. Details in section 6, "OBS overlay".
- **Source:** the MKOSZ netcasting page `https://netcasting4.webpont.com/?whun_<id>` (`whun_` = women, `hun_` = men, `hunu18_` etc. = junior games; verified 2026-11-24 on a live U19 game: the feed parses, the points match the score; junior clubs/players are not in the Hunbasket NB I/A data, so no logo/photo and the feed's own name spelling, e.g. "Gerg?" for Gergő – a quirk of the feed itself). It loads `storage/full<gamecode>.html` (whole game) / `storage/last<gamecode>.html` (latest events), refreshed about every 5 s. Format: home-made `key|value#key|value` text, `%` between array items; three string replaces turn it into JSON (`graphics/js/live.js` `decodeFeed`). Contains roster (`players.home/away`: Hunbasket player code, name, number, photo URL), `i` (teams, score `hp`/`vp`, arena, referees, date) and the play-by-play `f` (codes: 1000 made shot, 1001 miss, 1002 def reb, 1003 off reb, 1004 steal, 1005 turnover, 1006 foul drawn, 1007 foul, 1008 assist, 1009 block, 1010 block against, 1020 technical, 1011 substitution, 1100 15 s tick, 1101 period end; `gt` = elapsed game seconds). Shot type 3 = three, 4 = free throw, 1/2/5 = two. **Player codes are Hunbasket player ids**, so `graphics/players/<id>.webp` fits directly.
- **Parser:** `graphics/js/live.js` (counts the stats like the netcasting page; counted points equal the official score), tests `tests/live.test.mjs` on a saved finished game (`tests/fixtures/live/whun_135563.full.txt`, ETO Basket – CEKK Cegléd 90–48).
