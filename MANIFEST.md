## 1. Purpose
Basketball commentator tool for the Hungarian NB I/A (men + women, always separate):
1. **Közvetítőhub** (`index.html`, `css/dashboard.css`) – match preparation dashboard (schedule/results, standings, team pages, head-to-head, notes, news, match sheet).
2. **Graphics Studio** (`graphics/`) – browser-based broadcast graphics from the owner's PSD designs, exported as transparent 1920×1080 PNG (and a ZIP package per match).

It loads `storage/full<gamecode>.html` (whole game) / `storage/last<gamecode>.html` (latest events), refreshed about every 5 s. - **How:** `graphics/overlay.html` + `js/overlay.js` (transparent 1920×1080 canvas) read everything from the **link** (`overlay-params.js`: `?game=whun_135563&g=liveteam|liveleaders|livestat[&side&player&corner&stats|teamStats|leaderStats&refresh&token&debug=1]`; league from the game code), poll the relay every 5 s (2–60) with `no-store`, redraw only when the feed text changed, keep the last good picture on any error (nothing is ever drawn as an error text; `&debug=1` shows a status line). Same `bind*` / builders / `render` as the studio, so the look is identical (checked: ETO–Cegléd fixture renders all three). State is not in the page (reload-safe) and not shared between sources. `graphics/live.html` + `js/livelinks.js` is the **link maker** (game, graphic, ticked stats, player, preview iframe, copy button; remembers game/graphic/token in localStorage only).
- **Server:** `tools/serve.py` caches each game's feed (3 s) so N sources cost one upstream request per game, gzip, serves a copy ≤60 s old when upstream fails (`X-Live-Stale`), optional `--token` / `LIVE_TOKEN` (403 without `&token=`), `--host`. The studio's own relay call adds the token from `localStorage nbia.live.token` when set. **Reachability:** central computer behind a tunnel (**Cloudflare Tunnel recommended**: fixed https URL, nothing to install on the laptops; Tailscale would need an install + login on every laptop). Cloud relays cannot work (the feed server blocks cloud networks).
- **One code everywhere (owner 2026-11-25):** the netcasting code = the Hunbasket / mkosz.hu match code (`…/whun/whun_135579` → `netcasting4.webpont.com/?whun_135579`; youth `…/hunu18/hunu18_142733`), `gameCode()` takes any of those links. The link maker lists today's / coming NB I/A games from `data/men.json|women.json` (the match `url` ends in the code). **Central computer:** `python3 tools/live_server.py` starts `serve.py` with a stable token (`.live-server.json`, gitignored) + a Cloudflare tunnel and prints the link-maker address with the key.
- **VAL (owner 2026-11-25, checked against the page player by player, e.g. Forray 35, Mester 18 with 1 block against and 4 fouls):** the live graphics show **VAL** (label `VAL`, internal key still `eff`) = pts + reb + ast + stl + blk + **fouls drawn** − missed FG/FT − turnovers; fouls and blocks against are NOT subtracted (`efficiency()` in `live.js`, test `VAL equals the netcasting page`).
